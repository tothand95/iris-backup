# Button

Triggers an action with one of four visual variants and optional icon support.

## When to use

| Variant | Use when |
|---|---|
| **Primary** | Main call-to-action |
| **Secondary** | Supporting action alongside a primary action |
| **Ghost** | Low-emphasis or inline action |
| **Danger** | Destructive or irreversible action |

## Behavior notes

- Button text is projected content, not a `label` input.
- Layout follows the icons that are set: with neither icon the button is label-only, and each of `leadingIconName` and `trailingIconName` adds its own slot.
- `labelHidden` hides the projected label visually but keeps it in the DOM for accessibility, and collapses the button to a square. Both icon slots still render, so a hidden label with two icons stays wider than a square.
- The component does not provide built-in loading, full-width, or menu-trigger states.

## Accessibility

- The component relies on native button semantics for focus and keyboard activation.
- Project meaningful text content for every button. It is always the accessible name.
- With `labelHidden` the projected text is hidden visually but announced by screen readers — it is never optional.
- `type` defaults to `"button"`; set `type="submit"` when the button should submit a form.
