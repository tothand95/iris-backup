# Banner

A page-level alert banner for important status, warning, error, or success messaging.

## When to use

| Type | Use when |
|---|---|
| **Info** | Providing neutral information or context |
| **Warning** | Alerting the user to a potential issue |
| **Error** | Communicating a failure or blocking issue |
| **Success** | Confirming a completed action or positive outcome |

## With actions

Set `showActions` to render the inline action buttons, and give each one a label via
`primaryActionLabel` and `secondaryActionLabel`. An action with no label is not rendered, so set
the labels for the actions you actually want. They are visible button text — supply them already
translated; they are not part of `provideIrisUiLocalization()`.

<Canvas of={BannerStories.WithActions} />

## Behavior notes

- Error and warning banners use `role="alert"`. Info and success banners use `role="status"`.
- `supportingText` renders only when it is non-empty.
- `dismissable` controls whether the dismiss button is shown.
- Clicking dismiss hides the banner and emits `dismissed`.
- Once dismissed, the component stays hidden until it is recreated.

## Accessibility

- Provide meaningful text in `title`; it is always rendered and forms the main alert message.
- Error and warning banners use `role="alert"` (assertive live region). Info and success banners use `role="status"` (polite).
- The dismiss button label defaults to `"Dismiss"`. Override `dismissAriaLabel` when a localized or more specific label is needed.
- Primary and secondary actions are native buttons, so Enter and Space activate them without extra setup.
- Do not rely on color alone to communicate banner type.
